# 🤖 Project_Jarvis

## 📋 Sobre o Projeto
O **Project_Jarvis** não é apenas um chatbot; é um ecossistema de assistência virtual em desenvolvimento contínuo. O objetivo é criar um assistente local integrado, capaz de processar linguagem natural, gerenciar comandos de voz e interagir com o sistema operacional e dispositivos externos.

Este projeto nasce da vontade de entender a fundo a integração entre **IA**, **Desenvolvimento Web (ASP.NET)** e **Automação**.

---

## 🏗️ Arquitetura e Visão Técnica
Diferente de soluções prontas, o Jarvis está sendo construído com foco em:
* **Back-end Robusto:** Desenvolvido em C# com ASP.NET Core, priorizando performance e segurança.
* **Integração de IA:** Uso da API do Gemini para processamento cognitivo.
* **Interface Reativa:** Front-end focado em UX, com animações de estado (Listening/Searching/Speaking) inspiradas em sistemas como Alexa.
* **Escalabilidade:** Planejado para futuras integrações com Arduino e segurança via JWT.

---

## 🚀 Tecnologias Utilizadas
* **Linguagem:** C# (.NET 8+)
* **Framework:** ASP.NET Core
* **IA:** Google Generative AI (Gemini API)
* **Front-end:** HTML5, CSS3 (com foco em animações de sistema)
* **Ferramentas:** Visual Studio, NuGet, Git/GitHub
