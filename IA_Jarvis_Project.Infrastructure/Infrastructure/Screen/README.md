# Infrastructure/Screen – Analise de Tela (Fase 3)

Esta pasta sera responsavel pela captura e analise da tela do usuario.

## Fluxo planejado:
1. Captura de screenshot (PrintScreen via Windows API)
2. OCR para extrair texto da imagem
3. Envio do conteudo extraido para o motor de IA
4. Resposta do Jarvis sobre o que esta na tela

## Tecnologias previstas:
- System.Drawing para captura de tela
- Tesseract OCR ou API Vision do Google
